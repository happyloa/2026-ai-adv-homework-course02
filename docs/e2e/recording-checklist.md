# 真實綠界測試錄影清單

這份清單用於第二場作業要求的公開錄影。自動化測試是可重現的開發驗證；本清單則是要讓助教看見真實綠界測試交易與特店後台訂單。

## 錄影前

1. 準備一個可公開存取的 HTTPS 網址（例如 ngrok、Cloudflare Tunnel 或部署網址）。
2. 在 `.env` 設定 `BASE_URL` 為該 HTTPS 網址，並確認 `/api/ecpay/notify` 可從外部呼叫。
3. 使用綠界測試環境帳號與測試參數；不要使用正式金流帳號或真實卡。
4. 啟動網站並開啟瀏覽器自動化工具。若以本專案驗證自動操作，可先執行：

   ```powershell
   npm run test:e2e:headed
   ```

5. 開始螢幕錄影，確保網址列、Agent 對話與瀏覽器畫面都會被錄到。

## 必錄畫面順序

1. 顯示並呼叫 `.agents/skills/e2e-payment-test/SKILL.md`。
2. 由商品頁選取花禮，加入購物袋。
3. 註冊／登入，填寫收件資訊；可先故意送出空白欄位，呈現驗證錯誤。
4. 建立訂單，顯示花漾生活的待付款訂單頁。
5. 點擊「前往綠界安全付款」，進入 `payment-stage.ecpay.com.tw`。
6. 使用綠界官方測試方式完成付款，等待回到花漾生活「付款完成」頁。
7. 登入 `vendor-stage.ecpay.com.tw`，顯示剛建立的測試訂單與交易結果。
8. 可再回到訂單詳情，讓訂單編號、付款狀態與後台資料能互相對照。

## 影片上傳後

- 將影片設為「公開」或「知道連結者可觀看」。
- 把公開網址填到 `docs/SUBMISSION.md`。
- 建議影片標題：`AI 開發進化營第二場｜花漾生活綠界 E2E 測試`。
- 上傳前確認影片沒有 `.env`、JWT、HashKey、HashIV、個資或正式帳號密碼。
